# AudioCast 중계 진단

Windows에서 `실행.cmd`를 더블클릭하세요. Python 3.10 이상과 기본 Tkinter가 필요하며, 추가 패키지는 없어요.

1. PC와 폰을 같은 Wi-Fi에 연결해요.
2. AudioCast에서 중계를 시작하고 캡처를 승인해요. Cast 기기 연결은 필요 없어요.
3. 앱 설정의 `스트림 주소 복사`로 얻은 주소를 PC 프로그램에 붙여 넣어요.
4. `검사 시작`을 누르면 2초마다 재생목록을 읽고 새 조각을 받아 검사해요.
5. `기록 저장`은 최근 300줄과 요약을 저장해요. 중계 주소는 기록에 저장하지 않아요.

중계를 재시작하면 주소가 바뀔 수 있으니 새 주소를 복사해 주세요. HTTP 503은 시작 준비 중 정상 응답이에요. HTTP 404는 주소 변경 또는 조각 만료 가능성을 뜻해요.

## 검사 범위

- HTTP 연결, 응답 시간, 재생목록 갱신 정체와 검사 누락 구간
- 오디오 조각 수신, ADTS 프레임 길이·AAC-LC/48 kHz/스테레오 형식
- 조각의 실제 프레임 수와 재생목록에 적힌 길이 일치 여부

목록 길이는 폰이 제공하는 오디오 구간의 합계예요. 실제 기기의 버퍼나 지연시간이 아니에요.

이 도구는 오디오 디코딩·재생 및 Cast 수신기 에뮬레이션을 하지 않아요. 실제 Cast 검색·연결·출력 전환·볼륨·그룹 동기화·음질·수신기 지연은 Cast 기기로 검증해야 해요. 기본 검사 요청도 앱의 HTTP 요청 수에 포함돼요.
